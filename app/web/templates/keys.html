Connect an MCP client

Point any MCP client at the endpoint below and pass the key as a bearer token. The exact config shape varies by client; the essentials are: 

endpoint:  {{ public_base }}{{ mcp_path }}
header:    Authorization: Bearer <your-key>
The endpoint host is whatever address the client uses to reach this server — set it with MCP_PUBLIC_BASE_URL (currently {{ public_base }}). A client on this host uses localhost; from another machine, this host's LAN / tunnel address; from a container on this host, host.docker.internal. The same key also authorises the media routes, so the image and clip URLs returned by the tools are fetchable with it.
